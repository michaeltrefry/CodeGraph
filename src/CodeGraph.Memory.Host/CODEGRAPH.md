## Summary

CodeGraph.Memory.Host is an ASP.NET Core web API host that exposes a memory graph service — a knowledge graph system storing entities, claims, and their relationships. It provides REST endpoints for storing, querying, searching, and managing memory claims and entities, and also integrates with a message bus (via MassTransit consumers) to receive claim storage commands asynchronously. The project serves as the HTTP and messaging entry point for a persistent, graph-based memory layer used across the CodeGraph repository.
