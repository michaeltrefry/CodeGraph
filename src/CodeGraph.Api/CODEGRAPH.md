## Summary

CodeGraph.Api is the ASP.NET Core Web API layer for the CodeGraph platform, exposing HTTP endpoints for code analysis, repository reviews, AI-assisted querying, memory graph operations, LLM provider configuration, and MCP (Model Context Protocol) token management. It also acts as a message consumer, processing asynchronous pipeline events via MassTransit consumers that handle repository indexing, analysis batch submission, synthesis completion, and wiki page changes. The project serves as the integration hub between the frontend/clients and the underlying analysis, memory, and assistant services.
